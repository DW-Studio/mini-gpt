# mini-gpt：从零训练一个会"写莎士比亚"的 AI

一个极简的 GPT 训练示例：在 CPU 上、约 1 分钟内、用 11 万参数，从零训练一个字符级的迷你 GPT，让它学会「预测下一个字符」。这是理解大模型（LLM）原理的最小可跑实验。

配套文章：《我训练了一个会写莎士比亚的 AI，然后发现它什么都不懂》

## 快速开始

环境：Python 3.9+（Windows / macOS / Linux 均可，纯 CPU，不需要 GPU）

```bash
# 1. 安装依赖
pip install torch matplotlib

# 2. 训练（CPU 约 1 分钟）
python train.py --iters 4000

# 3. 画 loss 曲线
python plot_loss.py
```

跑完后，目录里会多出几个文件：

- `before.txt` — 训练前（随机初始化）模型生成的纯乱码
- `after.txt` — 训练后模型生成的「莎士比亚风格」文本
- `loss.csv` / `loss_curve.png` — 训练集 / 验证集的 loss 曲线
- `gpt_checkpoint.pt` — 训练好的模型权重

## 它到底做了什么

整个过程只有四步（完整注释见 `train.py`）：

1. 把 111 万个莎士比亚字符切成小段，每段：前 64 个字符是「输入」，每个字符的下一个是「标准答案」
2. 模型看着前 64 个字符，猜每个字符的下一个是什么
3. 猜错了，就用梯度下降把参数往「下次能猜对」的方向挪一点
4. 重复 4000 次

全程没有一行代码教它语法。它学会的只是「谁后面通常跟着谁」的统计规律——而这，就是大模型训练的本质，缩小亿万倍。

## 文件说明

| 文件 | 作用 |
|---|---|
| `train.py` | 训练主脚本（含完整的数据流注释） |
| `bench.py` | 测速脚本：扫不同模型配置的单步耗时 |
| `plot_loss.py` | 读 `loss.csv` 画 loss 曲线 |
| `input.txt` | 训练语料（莎士比亚全集，约 111 万字符） |

## 关键数字

- 词表：65 个字符（字符级，不是词级）
- 模型参数：108,352 个
- 训练：4000 步，CPU 约 1 分钟
- 训练集 loss：4.19 → 1.81
- 验证集 loss：一路降到约 1.88，之后开始回升（过拟合）

## 为什么值得跑一遍

你不需要理解任何公式。跑一遍，亲眼看到：

1. 一个随机初始化的网络，如何从「乱码」变成「会写莎士比亚」
2. loss 曲线一路下降，就是「学习」本身
3. 验证集 loss 到后期回升，就是「过拟合」

看完这三样，你对「大模型到底在训练什么」就有了直觉，而不是别人嘴里的二手结论。
